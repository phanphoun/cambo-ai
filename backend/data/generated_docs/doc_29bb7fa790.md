# សម័យអាណានិគមបារាំង (១៨៦៣ - ១៩៥៣)

## សេចក្តីផ្តើម
សម័យអាណានិគមបារាំង គឺជាដំណាក់កាលដ៏សំខាន់មួយនៅក្នុងប្រវត្តិសាស្ត្រកម្ពុជា ដែលបានចាប់ផ្តើមនៅឆ្នាំ ១៨៦៣ នៅពេលដែលព្រះបាទនរោត្តម បានចុះហត្ថលេខាលើសន្ធិសញ្ញាអាណាព្យាបាលជាមួយបារាំង ដើម្បីការពារប្រទេសពីការឈ្លានពានរបស់ប្រទេសជិតខាង។ សម័យកាលនេះបានបញ្ចប់ទៅវិញនៅឆ្នាំ ១៩៥៣ តាមរយៈការទាមទារឯករាជ្យដោយជោគជ័យរបស់ព្រះករុណា ព្រះបាទសម្តេចព្រះនរោត្តម សីហនុ។

## ១. ការចាប់ផ្តើមនៃអាណាព្យាបាល (១៨៦៣)
នៅពាក់កណ្តាលសតវត្សទី១៩ កម្ពុជាស្ថិតក្នុងស្ថានភាពទន់ខ្សោយដោយសារការគាបសង្កត់ពីសៀម និងយួន។ ព្រះបាទនរោត្តម បានសម្រេចចិត្តដាក់កម្ពុជាក្រោមអាណាព្យាបាលបារាំង ដើម្បីរក្សាអធិបតេយ្យភាពជាតិ។ តាមរយៈសន្ធិសញ្ញានេះ បារាំងទទួលបានសិទ្ធិគ្រប់គ្រងលើកិច្ចការបរទេស និងពាណិជ្ជកម្មរបស់កម្ពុជា។

## ២. ការគ្រប់គ្រងរបស់បារាំង
ក្នុងអំឡុងពេលនេះ បារាំងបានធ្វើការផ្លាស់ប្តូររចនាសម្ព័ន្ធរដ្ឋបាលកម្ពុជា៖
- **រដ្ឋបាល៖** បារាំងបានដាក់បញ្ចូលកម្ពុជាទៅក្នុងសហភាពឥណ្ឌូចិន (រួមជាមួយវៀតណាម និងឡាវ)។
- **ហេដ្ឋារចនាសម្ព័ន្ធ៖** បារាំងបានកសាងផ្លូវថ្នល់ ស្ពាន និងផ្លូវដែកមួយចំនួន ដើម្បីបម្រើដល់ការដឹកជញ្ជូនធនធានធម្មជាតិ។
- **ការអភិរក្សបេតិកភណ្ឌ៖** បារាំងបានបង្កើតសាលាបារាំងចុងបូព៌ា (EFEO) ដែលមានតួនាទីយ៉ាងសំខាន់ក្នុងការសិក្សាស្រាវជ្រាវ និងជួសជុលប្រាសាទនានានៅតំបន់អង្គរ។

## ៣. ចលនាតស៊ូដើម្បីឯករាជ្យ
ទោះបីជាស្ថិតក្រោមការគ្រប់គ្រងរបស់បារាំងក៏ដោយ ក៏ប្រជាជនខ្មែរមិនដែលបោះបង់ចោលនូវស្មារតីជាតិនិយមឡើយ៖
- **ចលនាប្រឆាំង៖** មានការបះបោរជាច្រើនប្រឆាំងនឹងការកេងប្រវ័ញ្ចពន្ធដារ និងការគ្រប់គ្រងរបស់បារាំង។
- **ការទាមទារឯករាជ្យ៖** ក្រោយសង្គ្រាមលោកលើកទី២ ស្មារតីជាតិនិយមបានកើនឡើងយ៉ាងខ្លាំង។ ព្រះបាទនរោត្តម សីហនុ បានដឹកនាំ "ប្រតិបត្តិការទាមទារឯករាជ្យ" យ៉ាងសកម្មតាមរយៈការទូត និងការតស៊ូផ្នែកនយោបាយ។

## ៤. ការទទួលបានឯករាជ្យ (៩ វិច្ឆិកា ១៩៥៣)
ដោយសារការតស៊ូយ៉ាងស្វិតស្វាញរបស់ព្រះមហាក្សត្រ និងប្រជាជនខ្មែរ បារាំងបានយល់ព្រមប្រគល់ឯករាជ្យពេញលេញជូនកម្ពុជាវិញនៅថ្ងៃទី ៩ ខែវិច្ឆិកា ឆ្នាំ ១៩៥៣។ ព្រឹត្តិការណ៍នេះត្រូវបានចាត់ទុកថាជាជ័យជម្នះដ៏ធំធេងនៃប្រវត្តិសាស្ត្រកម្ពុជាសម័យទំនើប។

## សេចក្តីសន្និដ្ឋាន
សម័យអាណានិគមបារាំងបានបន្សល់ទុកនូវឥទ្ធិពលចម្រុះទាំងផ្នែកអវិជ្ជមាន (ការកេងប្រវ័ញ្ចធនធាន) និងវិជ្ជមាន (ការអភិរក្សបេតិកភណ្ឌ និងប្រព័ន្ធរដ្ឋបាលទំនើប)។ ទោះជាយ៉ាងណាក៏ដោយ ការទទួលបានឯករាជ្យនៅឆ្នាំ ១៩៥៣ បានបើកទំព័រថ្មីមួយសម្រាប់កម្ពុជាក្នុងការកសាងជាតិដោយខ្លួនឯង។
